能。PokeSurvivor（宝可梦幸存者）的在线版支持 2–4 人合作，靠好友列表组队。下面讲怎么开房、一起玩时规则有什么不同，以及连不上时先查什么。规则来自[官方指南](https://pokesurvivor.com/en/guide/)、[开发者更新页面](https://pokesurvivor.com/en/news/)（均为英文）和游戏的[公开源代码](https://github.com/JPTER78/pokesurvivor)，2026-10-14 核对。游戏几乎每天都在更新，数值可能会变。游戏界面是英文的，下文会在括号里标出按钮原文。

## 联机前的准备

- **用在线版**。在 [pokesurvivor.com/en/](https://pokesurvivor.com/en/) 上玩。[itch.io](https://jpter78.itch.io/pokesurvivor) 的离线压缩包只能单人，存档也只在本地。
- **登录账号，设好昵称**。好友要靠昵称找到你，所以别用游客模式，用用户名加密码或 Google 登录。登录后还有云存档。游客和账号的区别见[新手教程](/zh/how-to-play/)。
- **至少一个好友**。一个联机房间要 2–4 人。
- **电脑或手机都行**。两边用的是同一个网页版，可以进同一个房间。手机上记得横屏玩。
- **在新标签页打开游戏**。浏览器会把嵌入框里的登录和官网分开，Google 登录还要弹窗。请在新标签页打开 pokesurvivor.com 登录和联机，别用本站首页的嵌入框。

## 开房步骤

  <img src="/images/co-op/friends-list.webp" width="1200" height="617" loading="lazy" decoding="async"
    alt="PokeSurvivor 好友（Friends）界面：显示自己的昵称、好友昵称输入框和 Add friend 按钮">
  <figcaption>好友（Friends）界面：把上面的昵称发给朋友，或者输入对方昵称后点 Add friend。</figcaption>

1. 所有人在 pokesurvivor.com 打开游戏并登录。游戏要求起昵称的话，用 3–16 个字母、数字或下划线（_）。
2. 打开好友列表（Friends），输入朋友的完整昵称，点添加好友（Add friend）。对方那边同意请求就加上了。
3. 房主（Host）在好友列表里点好友旁边的邀请（Invite）。第一次邀请时会自动建好房间并进入房间界面，不用另外开房。好友在线、而且不在对局中，才会出现邀请按钮。只有房主能邀请，邀请 3 分钟后失效。
4. 朋友接受邀请。房间里有 2–4 人后，房主点开始游戏（Start game），按钮上会显示人数，比如 3/4。所有人同时开局。

第一次玩？可以先各自看看[新手教程](/zh/how-to-play/)。操作和升级卡在联机时都一样。

## 合作规则：共享经验、复活、裂隙

<figure>
  <img src="/images/co-op/2-player-run.webp" width="1200" height="630" loading="lazy" decoding="async"
    alt="PokeSurvivor 两人联机对局：炎兔儿放出火花，旁边是队友的润水鸭，左上角显示队友的血条">
  <figcaption>2 人联机中：每人带着自己的伙伴，队友的名字和血条显示在左上角、你自己的血条下面。</figcaption>
</figure>

- **经验共享**。经验全队共用，不用每个人都去捡经验。
- **复活队友**。队友倒下后，站到队友身边就能把人救起来。
- **裂隙一起进**。进入裂隙时，全队一起进去。详见[神秘裂隙攻略](/zh/rifts/)。
- **房主别切页面**。房主切到别的标签页，所有人都会暂停。房主要一直停在游戏页面。
- **房主别退出**。房主退出，这一局所有人都结束。其他人退出的话，剩下的人可以继续玩。

### 敌人强度随人数增加

人越多，敌人越多也越耐打。以下倍率来自 2026-10-14 的游戏源代码：

| 人数 | 刷怪速度 | 敌人血量 |
|---|---|---|
| 1（单人） | ×1 | ×1 |
| 2 | ×1.75 | ×1.3 |
| 3 | ×2.5 | ×1.6 |
| 4 | ×3.25 | ×1.9 |

只要是多人对局，Boss 血量还会再 ×1.4。满 4 人时刷怪量是单人的 3 倍多，所以要散开站位，让每个人都在输出。

## 联机故障排查

以下做法是根据上面的规则整理的，开发者没有发布官方排查清单。

- **搜不到好友**：检查昵称有没有拼错，确认对方已经登录。游客没有账号，加不了。
- **提示「There's no player with that nickname」**：昵称要一字不差。让朋友从好友页面把自己的昵称复制给你。
- **提示「Can't connect to one of your friends」**：你或对方的网络不支持组队。让其中一人换个 Wi-Fi 或改用移动数据，游戏会自己重连。
- **提示「The invite has expired」**：邀请只有 3 分钟有效，让房主重新发一次。
- **提示「That room's game has already started」**：对局开始后就进不去了，等下一局。
- **提示「The room is full」**：一个房间最多 4 人。
- **在本站登录或邀请失败**：在新标签页单独打开 [pokesurvivor.com/en/](https://pokesurvivor.com/en/) 再试。点 Google 登录没反应的话，给这个网站开放弹出窗口权限。
- **找不到创建账号（Create account）选项**：游戏每月限制新账号数量，名额用完后要等到下个月才能注册。
- **游戏老是暂停**：多半是房主在切标签页或切应用。房主的游戏要保持在前台。
- **朋友用的是离线版**：itch.io 压缩包进不了房间，所有人都要用在线版。
- **用手机玩**：用 Safari 或 Chrome 横屏玩，别在 Discord、微信、Instagram 这类 App 的内置浏览器里打开，它们可能拦截 Google 登录。设置方法见[手机版怎么玩](/zh/mobile/)。

## 在线版与离线版对照

| | 在线版（pokesurvivor.com） | 离线压缩包（itch.io） |
|---|---|---|
| 人数 | 一个房间 2–4 人 | 1 人（只能单人） |
| 电脑和手机同房 | 支持 | 不支持 |
| 好友列表和房间 | 有 | 无 |
| 共享经验和复活 | 有 | 无 |
| 存档 | 登录后有云存档 | 只存在浏览器里 |
| 排行榜 | 有 | 无 |

## 联机安全吗？隐私提醒

联机时浏览器之间直接连接，原理和视频通话差不多，所以游戏的隐私说明提到，队友之间可能看到彼此的 IP 地址。直连不通时，会改走中转服务器。游戏内的说明写的是 Firebase，不过从 2026-10-12 起，源代码里换成了 Cloudflare 中转。不管哪种，都建议只和认识的人组队。

## 4 人组队推荐

下表是本站根据招式描述和种族值给出的建议，不是实测数据。经验是共享的，队伍可以分工，不必人人抢经验。

| 角色 | 作用 | 推荐伙伴 | 理由 |
|---|---|---|---|
| 输出 | 远程清怪 | 水跃鱼（Mudkip）、泪眼蜥（Sobble） | 水枪（Water Gun）是「可穿透的水柱，远近都稳定」，这两只在水枪伙伴里攻击倍率最高（1.08） |
| 控场 | 覆盖大范围 | 妙蛙种子（Bulbasaur）、菊草叶（Chikorita）、草苗龟（Turtwig）、敲音猴（Grookey） | 藤鞭（Vine Whip）是远距离、大扇形范围的鞭打 |
| 减速辅助 | 拖慢靠近的敌人 | 球球海狮（Popplio） | 泡沫（Bubble）碰到的敌人会减速 |
| 救人位 | 最先赶到倒地队友身边 | 呱呱泡蛙（Froakie） | 御三家里基础速度最高（108） |

- 攻击形状要搭配。穿透水柱和大扇形打的是不同方向，混搭的队伍身边死角更少。
- 稍微分散站位。一个人捡东西，其他人顶住怪潮。
- 进裂隙后更要散开，免得一招有预警的大招把全队一起打中。各裂隙场地和适合的招式见[神秘裂隙攻略](/zh/rifts/)。

各伙伴在不同阶段的强弱，看 [PokeSurvivor 强度榜](/zh/tier-list/)；第一只伙伴怎么选，看[开局选哪只伙伴](/zh/best-pokemon/)。
